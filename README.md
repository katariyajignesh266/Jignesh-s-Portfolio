# Jignesh's Portfolio Website

## Project Overview

This project is a personal portfolio website developed using HTML and CSS. The website is designed to showcase my profile, skills, education, projects, and contact information in a professional and responsive manner.

The main purpose of this portfolio website is to create an online presence where visitors, recruiters, and developers can learn about my background, technical skills, and completed projects.

---

## Features

* Responsive design for desktop, tablet, and mobile devices
* Professional navigation bar with smooth scrolling
* Hero section with profile image and introduction
* About Me section
* Skills section displaying technical skills
* Projects section showcasing completed projects
* Education section with academic information
* Contact section with email, phone number, and location
* Modern UI design using custom CSS styling
* Mobile-friendly layout with responsive adjustments
